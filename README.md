# Real Estate Sales and Marketing Analytics Dashboard

An Excel analytics project combining 2,280 CRM leads with bookings,
marketing spend, and sales targets to analyse sales and marketing performance.

## Tools Used
Excel, Power Query, Power Pivot, DAX, PivotTables, PivotCharts, slicers, and VBA.

## Dashboard Pages
- Executive Performance: Leads, site visits, bookings, and conversion.
- Marketing Performance: Marketing spend, cost per lead, and cost per booking.
- Project Performance: Booking value and funnel performance across projects.
- Target vs Actual: Executive booking results against targets.

## Key Features
- Power Query workflows for importing, cleaning, and combining source data.
- Data modelling and DAX measures for business KPIs.
- Interactive dashboards with slicers.
- VBA automation for data refresh, slicer reset, and PDF export.

## How to Explore
Download Real_Estate_Sales_Marketing_Dashboard_final.xlsm and open it
in Microsoft Excel desktop. Use the dashboard sheets and slicers to
explore the saved data.

## Refresh Requirements
Power Query currently references local source folders from the original
development computer. Refreshing requires the original source files
and updating their paths in Power Query.

The workbook includes saved data for exploring the dashboards without
refreshing. VBA buttons require macros to be enabled; enable them only
after reviewing and trusting the workbook.
